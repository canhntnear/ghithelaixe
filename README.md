# 🚗 VPK Driver & GPS Simulator

Game mini chạy trực tiếp trên trình duyệt, mô phỏng lái xe trên đường và dữ liệu từ thiết bị giám sát hành trình.

## Tính năng

- Điều khiển xe bằng **W/A/S/D** hoặc phím mũi tên.
- Tăng/giảm tốc, đánh lái và né xe trên đường.
- Màn hình thiết bị mô phỏng: tốc độ, GPS, thẻ lái xe, thời gian lái liên tục.
- Nhật ký telemetry/sự kiện: GPS fix, mất GPS, đăng nhập thẻ, va chạm, gửi sự kiện.
- Cảnh báo khi thời gian lái liên tục mô phỏng tiến gần/vượt 4 giờ.
- Không cần framework hoặc backend; chỉ một file HTML.

## Chạy

Mở `game/index.html` bằng trình duyệt hoặc deploy thư mục `game/` lên GitHub Pages/static hosting.

> Đây là mô phỏng giáo dục/truyền thông, không phải hệ thống giám sát hành trình thực tế và không dùng để xác định tuân thủ pháp luật.
